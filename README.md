# 🍽️ BreakFAST - Simple Tool for Security Testing

## 🌟 Overview
BreakFAST is a proof of concept for Kerberos Armoring abuse. This software helps security testers assess the strength of their Kerberos configurations. It is designed to be user-friendly and accessible for anyone looking to improve their system's security posture. 

## 🛠️ Features
- **User-Friendly Interface**: Easy to navigate for all users.
- **Detailed Reporting**: Provides clear results to help understand security risks.
- **Customizable Options**: Adjust settings to fit your testing requirements.
- **Active Development**: Regular updates based on user feedback and evolving security needs.

## 📊 Using BreakFAST
1. **Start a New Test**: 
   Once the application opens, click "New Test" to begin.
   
2. **Configure Settings**: 
   Set your desired parameters. You can choose different testing modes depending on your objectives.

3. **Run the Test**: 
   Click "Start Test". BreakFAST will run through the configured checks and present findings.

4. **Review Results**: 
   After the test completes, examine the detailed report. This will help you understand any vulnerabilities.
